01 · Análisis Estadístico Meteorológico

Regresión, test de hipótesis y análisis no paramétrico aplicado a datos meteorológicos.

Descripción del proyecto

Proyecto académico desarrollado en la Maestría en Ciencia de Datos de la UNAJ. El trabajo analiza datos diarios de una estación meteorológica ubicada en Corrientes, Mercedes, durante el período 2023–2024.

El objetivo fue aplicar estadística descriptiva, regresión lineal, test de hipótesis y métodos no paramétricos para estudiar la relación entre temperatura, humedad, presión atmosférica y radiación solar global.

Dataset utilizado

Dataset meteorológico con 554 registros diarios. Incluye fecha de medición, temperatura del aire a 150 cm, humedad media, presión media y radiación global. La variable principal de análisis fue la radiación solar global.

Ver dataset original

Herramientas y conceptos aplicados

Python Pandas NumPy Matplotlib Seaborn SciPy Statsmodels Regresión lineal Test de hipótesis Spearman Análisis meteorológico

Principales resultados

  • Temperatura y radiación muestran estacionalidad anual marcada.
  • Existe relación positiva entre temperatura del aire y radiación solar global.
  • El modelo simple Temperatura → Radiación obtuvo un R² aproximado de 8.58%.
  • El modelo múltiple con Temperatura, Humedad y Presión elevó el R² a 45.79%.
  • La humedad presentó efecto negativo sobre la radiación solar.
  • Spearman confirmó la robustez de la relación observada.
