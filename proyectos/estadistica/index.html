Proyecto de Estadística

Proyecto orientado al análisis estadístico de datos técnicos, interpretación de resultados y generación de conclusiones para soporte a la toma de decisiones.

Objetivo

Aplicar herramientas estadísticas para analizar información proveniente de ensayos, procesos técnicos, indicadores de gestión o datos de proyectos.

Herramientas aplicadas

  • Estadística descriptiva
  • Análisis exploratorio de datos
  • Excel
  • Python
  • Visualización de datos
  • Interpretación técnica de resultados

Aplicación profesional

Este proyecto conecta análisis estadístico, ingeniería civil y ciencia de datos para mejorar la lectura de información técnica y apoyar decisiones.
