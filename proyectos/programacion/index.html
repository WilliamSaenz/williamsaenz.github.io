01 · Sistema de Información Académica Interactivo

Aplicación web basada en un proyecto Python de gestión académica. Permite cargar estudiantes, importar archivos CSV o Excel, calcular promedios, analizar rendimiento por materia, visualizar indicadores y exportar resultados.

El objetivo es transformar un script académico en una herramienta práctica de consulta, pensada para docentes, coordinadores o instituciones que quieran revisar el desempeño de un curso de forma rápida y visual.

Carga de datos Base de ejemplo, ingreso manual e importación de CSV o Excel.
Análisis académico Promedios, situación del estudiante, ranking y rendimiento por materia.
Dashboard Indicadores, gráficos y exportación de información para seguimiento.
