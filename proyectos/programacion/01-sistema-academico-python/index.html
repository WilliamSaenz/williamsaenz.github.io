01 · Sistema Académico en Python

Programa para analizar rendimiento estudiantil en una maestría.

Descripción del proyecto

Proyecto académico desarrollado en el marco de la Maestría en Ciencia de Datos. El sistema permite leer información de estudiantes desde un archivo CSV, procesar calificaciones, calcular promedios y presentar resultados académicos de forma organizada.

Herramientas aplicadas

Python CSV Análisis de datos Programación orientada a objetos Documentación técnica Gestión académica

Qué hace el programa

  • Lee una base de datos de estudiantes desde un archivo CSV.
  • Organiza la información académica de cada estudiante.
  • Calcula promedios y resultados de desempeño.
  • Permite analizar rendimiento estudiantil por asignaturas.
  • Presenta una estructura modular mediante archivos Python separados.
