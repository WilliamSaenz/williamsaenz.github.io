# CivilScope Obras Civiles · Guía pública para GitHub Pages

Este paquete contiene una guía técnica interactiva dividida en tres módulos:

1. Mecánica de Suelos
2. Geotecnia Aplicada
3. Pavimentos

## Criterio de publicación

Este proyecto NO incluye PDFs, PPTX, capturas ni documentos privados. Los gráficos fueron redibujados como SVG propios y el texto fue redactado como material didáctico/técnico original.

## Cómo subirlo a GitHub Pages

Opción recomendada:

```text
repo/
└── obras-civiles/
    ├── index.html
    ├── mecanica-suelos/
    ├── geotecnia-aplicada/
    ├── pavimentos/
    └── assets/
```

Luego activar GitHub Pages desde `Settings > Pages`.

## Archivos principales

- `index.html`: hub general.
- `mecanica-suelos/index.html`: módulo de ensayos y comportamiento del suelo.
- `geotecnia-aplicada/index.html`: investigación, cimentaciones, contenciones, taludes e instrumentación.
- `pavimentos/index.html`: subrasante, materiales, mezclas, control de obra y fallas.
- `assets/data/content.js`: contenido editable.
- `assets/img/*.svg`: gráficos técnicos propios.

## Uso

Guía orientativa para docencia, consulta técnica preliminar y organización de criterio. No reemplaza estudio geotécnico, diseño vial, normativa vigente, laboratorio acreditado ni firma profesional.
