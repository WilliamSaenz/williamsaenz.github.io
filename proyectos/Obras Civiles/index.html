Guía práctica para obra, laboratorio y criterio técnico

Proyecto preparado para GitHub Pages. Está separado en tres demos para evitar saturación: mecánica de suelos, geotecnia aplicada y pavimentos. Las imágenes son SVG propios y las interpretaciones son orientativas para formación y consulta técnica preliminar.

Importante: no se incluyen documentos privados, diapositivas ni archivos de empresas. Las fuentes internas se usan sólo como apoyo conceptual; el material publicado es redibujado y redactado desde cero.

1. Mecánica de Suelos

Ensayos de laboratorio, gráficos e interpretación: granulometría, Atterberg, Proctor, consolidación, corte directo, triaxial y más.

2. Geotecnia Aplicada

Investigación del subsuelo, perforaciones, ensayos in situ, cimentaciones, contenciones, taludes e instrumentación.

3. Pavimentos

Subrasante, bases, subbases, mezclas asfálticas, pavimento rígido, ensayos, control de obra y fallas típicas.

Cómo usarlo en GitHub

Subí toda la carpeta al repositorio. Si ya tenés una sección de obras civiles, podés colocar este paquete como subcarpeta obras-civiles.
