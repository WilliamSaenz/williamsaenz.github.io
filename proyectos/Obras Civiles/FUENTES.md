# Fuentes y respaldo técnico

## Criterio de publicación

Este paquete fue preparado para publicación en GitHub Pages sin incluir material privado. No se adjuntan PDFs, PPTX, capturas, logos ni documentos de terceros. Las fuentes privadas o de clase se usaron únicamente como apoyo conceptual interno.

## Normativa y referencias públicas recomendadas

### Colombia
- Reglamento Colombiano de Construcción Sismo Resistente NSR-10, Título H: Estudios Geotécnicos.
- INVIAS: Manual de Normas de Ensayo de Materiales para Carreteras.
- INVIAS: Especificaciones Generales de Construcción de Carreteras.

### Argentina
- INTI-CIRSOC: Reglamentos Nacionales de Seguridad Estructural.
- CIRSOC 401: Reglamento Argentino de Estudios Geotécnicos.
- INPRES-CIRSOC: Reglamentos sismorresistentes cuando corresponda.

### Normas de ensayo de referencia
- ASTM D2488: descripción visual-manual de suelos.
- ASTM D422 / ASTM D6913: granulometría.
- ASTM D4318: límites de Atterberg.
- ASTM D854: gravedad específica.
- ASTM D2434: permeabilidad de suelos granulares.
- ASTM D698 / D1557: Proctor estándar y modificado.
- ASTM D1556: densidad in situ por cono de arena.
- ASTM D2435: consolidación unidimensional.
- ASTM D2166: compresión inconfinada.
- ASTM D3080: corte directo.
- ASTM D2850 / D4767 / D7181: triaxiales UU/CU/CD.
- AASHTO T 99 / T 180: compactación.
- AASHTO T 193: CBR.
