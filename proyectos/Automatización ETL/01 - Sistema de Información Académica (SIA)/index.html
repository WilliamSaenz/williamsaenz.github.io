01 · Sistema Académico Interactivo

Prototipo web para registrar estudiantes, analizar rendimiento académico y visualizar indicadores del curso.

Resumen ejecutivo

Sistema académico interactivo inspirado en un proyecto desarrollado en Python. Permite cargar estudiantes, calcular promedios, buscar por legajo, evaluar la situación académica, comparar materias y visualizar gráficos de rendimiento.

Base de datos del curso

Elegí cómo querés iniciar el análisis: usar una base de ejemplo, comenzar desde cero o importar tu propio archivo de estudiantes en formato CSV o Excel.

Usar base de ejemplo

Carga estudiantes de prueba para recorrer el sistema, ver indicadores y validar el funcionamiento.

Comenzar desde cero

Limpia la base local y permite que el docente cargue estudiantes manualmente desde el formulario.

Importar archivo CSV o Excel

El archivo debe incluir las columnas: Legajo, Nombre, Apellido, Programación, Base de Datos, Análisis Estadístico, Arquitecturas en la Nube, Aprendizaje Automático y Captura de la Información.

CSV funciona directamente. Para Excel, la página usa una librería JavaScript externa para leer archivos .xlsx desde el navegador.

Dashboard del curso

Ingreso de estudiantes

Ingresá la cantidad de estudiantes que querés cargar. El sistema genera los formularios, valida notas entre 1 y 10 y asigna legajos automáticamente.

Buscar estudiante por legajo

Promedios individuales

Tabla de seguimiento estudiante por estudiante: promedio con aplazos, promedio sin aplazos, cantidad de materias aprobadas y situación académica.

Promedio y aprobación por materia

Comparación del rendimiento por asignatura para detectar fortalezas, materias críticas y áreas donde conviene reforzar acompañamiento académico.

Detalle por materia

Gráficos principales

Promedio por asignatura

Permite ver qué materias concentran mejor o menor rendimiento promedio.

% aprobación por asignatura

Permite detectar materias con mayor riesgo académico.

Distribución académica

Resume estudiantes aprobados y reprobados según criterio de aprobación total.

Ranking de promedios

Ordena estudiantes por rendimiento general y permite detectar extremos.

Conclusiones prácticas

Detectar materias críticas

El promedio y el porcentaje de aprobación por materia ayudan a decidir dónde reforzar clases, tutorías o materiales de apoyo.

Priorizar estudiantes en riesgo

La búsqueda por legajo y los promedios individuales permiten identificar alumnos con aplazos o varias materias desaprobadas.

Medir desempeño del curso

El dashboard resume total de estudiantes, aprobación general, mejor estudiante y materia con mayor o menor rendimiento.

Convertir notas en decisiones

El sistema transforma un archivo de notas en indicadores claros para gestión académica, seguimiento docente y mejora continua.

Acciones de datos

Nota: esta versión funciona como prototipo web estático. Los datos nuevos se guardan en el navegador mediante almacenamiento local. Para uso institucional multiusuario se necesitaría una base de datos.
