Resumen ejecutivo

Este sistema permite trabajar de tres formas: descargar una plantilla Excel editable, importar esa plantilla con las materias que el usuario defina, o usar la base precargada de estudiantes para hacer análisis inmediato.

Excel editable Materias dinámicas Base precargada Dashboard Diagnóstico Toma de decisiones

Gestión de datos

Flujo recomendado: descargá el template Excel, editá las materias si hace falta, completá los estudiantes y volvé a cargar el archivo.

1 · Descargar template editable

Podés modificar, agregar o quitar materias desde esta lista antes de descargar el Excel. También podés cambiar los nombres de materias directamente en el archivo.

2 · Cargar template o archivo

El sistema detecta automáticamente las materias del archivo. Las columnas fijas son: Legajo, Nombre y Apellido. Todo lo demás se interpreta como materia.

3 · Usar base precargada

Carga los estudiantes precargados originales para analizar el sistema sin subir archivos.

4 · Exportar resultados

Exporta la base actual en Excel o CSV compatible con Excel. Para evitar errores de tildes, se recomienda Excel.
