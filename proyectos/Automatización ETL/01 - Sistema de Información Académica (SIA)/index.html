Acciones rápidas

Usá esta zona para descargar una plantilla, cargar datos, exportar resultados y reiniciar el sistema. La opción recomendada es trabajar con Excel .xlsx.

1 · Descargar plantilla Excel

Genera un archivo .xlsx listo para completar con estudiantes y notas. Esta opción evita problemas con tildes y caracteres especiales.

2 · Importar archivo

Subí el Excel completado o un CSV. El sistema validará nombres, legajos y notas entre 1 y 10.

3 · Exportar resultados

Descargá la base actual en Excel o CSV corregido para abrir en Excel sin romper tildes.

4 · Base del sistema

Cargá datos de ejemplo o comenzá desde cero. Ideal para probar el sistema sin tocar archivos.
