01 · Sistema Académico Interactivo

Cargar datos, diagnosticar rendimiento académico y tomar decisiones con indicadores claros.

Acciones rápidas

Trabajá con tres caminos: descargar un template Excel editable, cargar ese template con las materias que quieras, o usar la base precargada de alumnos para analizar directamente.

1 · Descargar template Excel editable

Podés modificar, agregar o quitar materias desde esta lista. El Excel se genera con hojas de notas, instrucciones, materias y ejemplo. Recomendado para evitar problemas con tildes.

2 · Cargar template o archivo

Subí el Excel completado. Las columnas fijas son Legajo, Nombre y Apellido. Toda columna posterior se toma como materia.

3 · Usar alumnos precargados

Restaura la base original con 31 estudiantes y las seis materias iniciales del sistema.

4 · Exportar resultados

Exporta la base actual, incluyendo las materias activas. El Excel incluye una hoja de diagnóstico.
