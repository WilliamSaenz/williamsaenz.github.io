Proyecto de Presupuestos

Proyecto orientado a la elaboración, organización y análisis de presupuestos técnicos para obras civiles, geotecnia e infraestructura.

Objetivo

Mostrar el manejo de información técnica, cubicaciones, análisis de precios unitarios, costos directos, indirectos y reportabilidad para toma de decisiones.

Herramientas aplicadas

  • Excel avanzado
  • Power Query
  • Presupuestos
  • Cubicaciones
  • Análisis de precios unitarios
  • Reportabilidad técnica

Aplicación profesional

Este proyecto refleja habilidades vinculadas con oficina técnica, control de costos, planificación y gestión ejecutiva de información.
